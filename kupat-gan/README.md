# קופת גן

מערכת לגבייה מהורים בגנים ובכיתות: משלוח מנות לגננת, מתנת סוף שנה וכדומה.
במקום שהורה מתנדב יתקשר לכל ההורים, יאסוף מזומן וירדוף אחרי מי שלא שילם,
המערכת מחייגת להורים באופן אוטומטי. ההורה שומע כמה עליו לשלם ומשלם בכרטיס אשראי
בהקשה בטלפון. גם בטלפון כשר, בלי אינטרנט ובלי קישורים.

## מה המערכת עושה

**לאחראית הגבייה (ממשק ניהול באתר):**
- הקמת גן או כיתה, וייבוא רשימת ילדים וטלפונים בהדבקה מאקסל או מקובץ CSV.
  מספרים מזוהים בכל פורמט (‎052-7654321‎, ‎+972...‎, וגם בלי ה-0 שאקסל מוחק).
  יש בדיקה לפני הייבוא, וכל שורה שגויה מוצגת עם הסיבה.
- יצירת גבייה: נושא, סכום לילד, מספר ניסיונות חיוג וכמה שעות לחכות בין ניסיון לניסיון.
- הפעלה, השהיה וסגירה של החיוג.
- מסך מעקב: כמה נאסף, מי שילם באשראי, מי במזומן ומי עדיין לא.
- סימון "שולם במזומן" למי שבכל זאת שילם במזומן.
- סימון "פטור": משפחה שלא תחויב ולא יתקשרו אליה, בלי שאף אחד יידע.
- כפתור "חייג עכשיו" להורה מסוים, ואיפוס מונה החיוגים.
- ייצוא לאקסל (CSV).
- יומן שיחות ועסקאות.
- סימולטור טלפון: אפשר לנסות את כל השיחה מהדפדפן לפני שמחברים טלפוניה אמיתית.

**להורים (בטלפון):**
- שיחה אוטומטית שמקריאה את שם הילד, נושא הגבייה והסכום.
- אם יש תאומים או כמה ילדים עם אותו מספר טלפון: שיחה אחת וחיוב אחד על הסכום הכולל.
- התפריט: 1 תשלום באשראי, 2 "כבר שילמתי במזומן" (נשלח לאחראית לאימות),
  3 שמיעה חוזרת, 0 "התקשרו אליי בפעם אחרת".
- הקשת מספר כרטיס, תוקף, תעודת זהות ו-CVV, אישור הסכום וקבלת מספר אישור.
- בדיקת תקינות לפני החיוב (ספרת ביקורת של הכרטיס ושל תעודת הזהות, תוקף).
  אם הקלט שגוי, הוא מתבקש שוב.
- אם הכרטיס נדחה, אפשר לנסות כרטיס אחר.
- הורה יכול גם להתקשר בעצמו בכל זמן. המערכת מזהה אותו לפי מספר הטלפון,
  ואם הוא מתקשר ממספר אחר היא מבקשת להקיש את המספר הרשום.

**חיוג אוטומטי מכבד:**
- רק בשעות שהוגדרו (ברירת מחדל: 09:30 עד 20:30, שעון ישראל).
- אין חיוג בשבת, ביום טוב ובתשעה באב. התאריכים מחושבים לפי הלוח העברי, כך שאין צורך לעדכן אותם כל שנה.
- ביום שישי ובערב חג החיוג נעצר מהשעה 12:00.
- אפשר להוסיף תאריכים חסומים נוספים.
- ניסיון ראשון למספר הראשי, ניסיון שני למספר הנוסף (של ההורה השני), וכן הלאה לסירוגין.

## הפעלה מהירה (מצב ניסיון, בלי טלפוניה ובלי סליקה אמיתית)

דרוש Node.js בגרסה 22.13 ומעלה. אין צורך להתקין חבילות נוספות.

```bash
cd kupat-gan
cp .env.example .env          # ערכו ADMIN_PASSWORD ו-APP_SECRET
npm start
```

פתחו את http://localhost:3000, היכנסו עם הסיסמה, הקימו גן, ייבאו רשימה, צרו גבייה
והפעילו אותה. אחר כך נסו את השיחה במסך "סימולטור טלפון".

הרצת הבדיקות: `npm test`

## חיבור לטלפוניה

### ימות המשיח (מומלץ)

1. בקובץ `.env` הגדירו `PHONE_PROVIDER=yemot`, את מספר המערכת והסיסמה (`YEMOT_NUMBER`, `YEMOT_PASSWORD`),
   ואת `PUBLIC_URL`, הכתובת הציבורית של השרת. היא חייבת להיות ב-https.
2. הגדירו `APP_SECRET` קבוע. בלעדיו כתובת ה-API משתנה בכל הפעלה מחדש.
3. צרו שלוחה מסוג API. את הכתובת לשדה `api_link` תמצאו במסך "הגדרות" במערכת,
   והיא גם מודפסת כשהשרת עולה. לדוגמה, בקובץ `ext.ini` של השלוחה:
   ```
   type=api
   api_link=https://your-server/ivr/yemot/XXXXXXXX
   api_hangup_send=yes
   ```
   כדי שהורים יוכלו גם להתקשר בעצמם, נתבו את השיחות הנכנסות לשלוחה הזו.
4. לשיחות יוצאות: צרו במערכת תבנית קמפיין שמעבירה שיחה שנענתה לשלוחת ה-API,
   ורשמו את מזהה התבנית ב-`YEMOT_TEMPLATE_ID`. המערכת מפעילה את הקמפיין דרך `RunCampaign`.

> **חשוב:** את שמות הפרמטרים של ה-API של ימות המשיח (`RunCampaign` ו-`read=`) ואת הגדרות התבנית
> צריך לאמת מול התיעוד העדכני של ימות המשיח לפני העלייה לאוויר. כל ההתאמה לימות המשיח
> נמצאת בקובץ אחד, `src/ivr/yemot.js`, כך שתיקון יהיה פשוט.

### Twilio (חלופה)

הגדירו `PHONE_PROVIDER=twilio` ואת פרטי החשבון. במספר שב-Twilio הגדירו את ה-Voice URL
ל-`{PUBLIC_URL}/ivr/twilio/voice` (POST). כל בקשה מ-Twilio נבדקת לפי החתימה שלה.

## חיבור לסליקה: טרנזילה

הגדירו `PAYMENT_PROVIDER=tranzila`, ואת `TRANZILA_SUPPLIER` ו-`TRANZILA_PASSWORD` (שם המסוף והסיסמה).
החיוב נשלח ישירות לטרנזילה, ונחשב מאושר רק כשהקוד שחוזר הוא `000`.
לפני שעוברים למסוף אמיתי, בדקו קודם על מסוף בדיקות.

### אבטחת מידע: חובה לקרוא לפני עלייה לאוויר

- **פרטי האשראי לא נשמרים בשום מקום.** הם נמצאים בזיכרון רק בזמן השיחה ונמחקים מיד אחרי ניסיון החיוב.
  במסד הנתונים נשמרות רק 4 הספרות האחרונות ומספר האישור.
- מכיוון שמספר הכרטיס עובר דרך השרת (מהמרכזייה אל טרנזילה), השרת נכלל בתקן **PCI-DSS**.
  לשימוש בהיקף רחב כדאי לשקול אחת משתי חלופות:
  מודול סליקה מובנה של מערכת הטלפוניה (למשל דרך ספק סליקה שמתממשק לימות המשיח),
  שבו פרטי הכרטיס לא עוברים דרך השרת שלנו כלל, או התייעצות עם טרנזילה לגבי הפתרון הטלפוני שלהם.
- אסור לרשום ביומני השרת (logs) את כתובות ה-URL של הבקשות מימות המשיח. ימות המשיח מחזירה את
  ערכי ההקשות בכתובת עצמה. הקוד לא רושם אותן, וחשוב לוודא שגם שרת ה-proxy או ה-hosting לא רושם אותן.
- חובה להשתמש ב-https.

### שאלה עסקית: לאן הכסף נכנס?

החיוב עובר דרך מסוף סליקה, ומסוף כזה מחייב עוסק רשום. יש שתי אפשרויות:
לכל ועד הורים מסוף משלו (לא מעשי ברוב המקרים),
או מפעיל אחד של השירות שגובה ומעביר את הכסף לאחראית הגבייה.
באפשרות השנייה כדאי לבדוק את ההיבט הרגולטורי ואת ההיבט החשבונאי מול רואה חשבון.

## מבנה הקוד

```
src/
  server.js        הפעלת השרת והמחייג
  app.js           ממשק ה-API, הרשאות, נקודות הקצה של הטלפוניה
  db.js            מסד נתונים (SQLite מובנה ב-Node)
  schedule.js      שעות חיוג, שבת, ימים טובים ותשעה באב לפי הלוח העברי
  dialer.js        סבב חיוג: מי מקבל שיחה, קיבוץ משפחות, ניסיונות חוזרים
  importer.js      ייבוא רשימות
  phone.js         נרמול מספרי טלפון ישראליים
  ivr/flow.js      השיחה עם ההורה, בלי תלות בספק הטלפוניה
  ivr/yemot.js     התאמה לימות המשיח
  ivr/twilio.js    התאמה ל-Twilio
  payments/        טרנזילה, סליקת בדיקה ובדיקות תקינות לכרטיס
public/            ממשק הניהול (עברית, מותאם לנייד)
test/              בדיקות אוטומטיות
```

## רעיונות להמשך

- SMS עם קישור לתשלום (גם ב-Bit) למי שיש לו סמארטפון.
- שליחת אישור תשלום ב-SMS והפקת קבלה.
- כמה אחראיות גבייה, עם הרשאות נפרדות לכל גן.
- סכום שונה לכל ילד, למשל הנחה לאחים.
- תרומה מרצון מעבר לסכום.
- דוח אוטומטי לאחראית הגבייה בסוף כל יום חיוג.
- חיבור למודול סליקה טלפוני מובנה, כדי לצמצם את היקף ה-PCI.
